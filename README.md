# DungeonPuzzle

Juego de puzzles de mazmorras desarrollado en Unity.

## Requisitos

### Version de Unity

**Este proyecto requiere Unity `6000.5.0b10` exactamente.**

> **Importante:** Abrir el proyecto con cualquier otra version de Unity causara que los archivos `ProjectSettings/ProjectVersion.txt` y `ProjectSettings/ProjectSettings.asset` sean sobreescritos automaticamente. Esto puede introducir cambios no intencionales en el historial de git.

Para descargar la version correcta, usa **Unity Hub** y busca la version `6000.5.0b10` en el archivo de versiones.

## Configuracion del proyecto

1. Instala Unity `6000.5.0b10` via Unity Hub
2. Clona el repositorio
3. Abre el proyecto desde Unity Hub seleccionando la carpeta raiz
4. Verifica que Unity Hub utiliza la version `6000.5.0b10` antes de abrir
